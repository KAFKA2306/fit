# プロジェクトコンセプト：全自動・衣装リターゲットシステム

このプロジェクトは、Blender上で「あるキャラクターの衣装を、別のキャラクターへ全自動でフィットさせる」ことを目的としたツールです。

## 何ができるの？

1.  **体型に合わせた変形 (RBF変形)**
    *   単に拡大縮小するのではなく、筋肉の付き方や体型の違いを考慮して、衣装を「吸い付くように」フィットさせます。
2.  **アクセサリーの維持 (OBB仕分け)**
    *   布地は柔らかく変形させますが、ボタンやバックルなどの「硬いパーツ」は形を崩さずに位置だけを調整します。
3.  **ウェイト（動き）の転送**
    *   元の衣装が持っていた動きのデータを、新しいキャラクターの骨格に合わせて自動で書き換えます。
4.  **シェイプキーの同期**
    *   「胸を大きくする」「太らせる」といった体型変更パラメータも、衣装側に自動でコピーされます。

## 開発の背景

これまで、衣装を別のアバターに着せる作業は、プロのモデラーでも数時間〜数日かかる重労働でした。このツールは、その「単純だけど難しい作業」をAIと幾何学の力で数分に短縮します。

「誰でも、好きな服を、好きなキャラに着せられる世界」を目指しています。
