# 体型変化に追従する魔法：シェイプキー同期

多くのアバターには、胸のサイズや身長を変えるための「シェイプキー（ブレンドシェイプ）」が備わっています。

## オートクチュールな自動生成

このシステムは、衣装のリターゲットが終わった後に、アバターが持っているシェイプキーをすべてスキャンします。
そして、「もしアバターの胸が大きくなったら、この衣装はどう伸びるべきか？」を計算し、衣装側にも全く同じ名前のシェイプキーを自動で作成します。

## 同期のメリット

Unityなどでアバターを動かす際、服のサイズを手動で調整する必要がなくなります。
アバター側のパラメータをいじるだけで、衣装もまるで「生きている布」のように、その形状に合わせて伸縮します。
これにより、一つの衣装データで、あらゆる体型のバリエーションに対応することが可能になります。
