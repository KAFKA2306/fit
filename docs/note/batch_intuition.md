# 自動化のメリット：一括処理（バッチ実行）

たくさんの衣装を一つずつ手作業で変換するのは大変です。このシステムは「一括処理（バッチ）」を前提に設計されています。

## ロボット工場のような仕組み

一つのフォルダに変換したい衣装（FBXファイル）をすべて入れておけば、あとはツールが順番に処理していきます。
夜寝る前にセットしておけば、朝にはすべての衣装が新しいアバター用に対応完了している、といった使い方が可能です。

## 失敗しても止まらない

もし、特定の衣装でエラーが起きても、システムはそこで止まりません。
「その衣装はスキップして次へ」と進むため、大量のデータを安定して処理することができます。

これは、個人のクリエイターだけでなく、大量の資産を持つ企業にとっても強力な武器になります。
