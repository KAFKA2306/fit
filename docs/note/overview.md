# システム全体の構成と流れ

このシステムは、複雑なリターゲット処理を複数のステップに分けて実行しています。

## 処理の5段階

1.  **初期化 (Initialization)**
    *   シーンの掃除や、アバター・衣装データの読み込みを行います。
2.  **身体の解析 (Body Analysis)**
    *   アバターの体型データを取得し、どこが胸でどこが腰か、といった情報を整理します。
3.  **幾何学的フィット (Geometric Fitting)**
    *   RBF（放射基底関数）を使い、衣装のメッシュをアバターの肌に沿わせます。
4.  **リギング転送 (Rigging Transfer)**
    *   骨の動きのデータ（ウェイト）を、近接頂点から計算してコピーします。
5.  **仕上げ (Finalization)**
    *   不要なデータの削除や、FBXとしての書き出し準備を行います。

## 安全設計

各ステップは独立しており、途中で問題が起きても、どこまで進んだかが分かりやすい構造になっています。
また、元のデータを壊さないよう、常にコピーに対して処理を行うように設計されています。
