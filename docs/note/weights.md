# 動きを伝える魔法：ウェイト転送

3Dモデルが動くのは、中にある「骨（ボーン）」に合わせて、各頂点がどれくらい付いていくかという設定（ウェイト）があるからです。

## 透明な「糸」のコピー

衣装を新しく作り直しても、そのままでは動きません。そこで、アバターが持っている「動きのレシピ」を衣装にコピーします。
1.  衣装の各頂点から、アバターの肌の一番近い場所を探します。
2.  その場所のウェイト設定を読み取ります。
3.  衣装の頂点に、その設定を書き込みます。

## ノイズの自動除去

単純にコピーするだけだと、脇の下や股関節などで、反対側の足の動きを拾ってしまう「ノイズ」が発生することがあります。
このツールは、解剖学的にありえない動きを自動で検知し、滑らかに補正する機能を備えています。

これにより、アバターが足を上げた時にスカートが変に引っ張られる、といったトラブルを防いでいます。
