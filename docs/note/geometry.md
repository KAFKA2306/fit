# 身体に沿った変形の仕組み：RBF（放射基底関数）

衣装を別のアバターに着せるとき、ただ拡大縮小するだけでは、身体のラインに綺麗にフィットしません。そこで使われるのが「RBF」という数学的な手法です。

## ゴムのように伸び縮みする空間

RBFは、空間そのものを「ゴム」のように変形させる技術です。
1.  アバターの肌にある「基準点」を決めます。
2.  その点が新しいアバターの肌でどこに移動したかを計算します。
3.  その移動量に合わせて、周りの空間（＝衣装）をふわっと滑らかに変形させます。

## なぜRBFなのか？

リニアな変形（単純な引き伸ばし）だと、関節部分でメッシュが潰れたり、不自然なシワができたりします。
RBFは、各頂点の影響を「距離」に応じて滑らかに減衰させるため、まるで熟練の仕立て屋がアイロンを当てたような、自然な仕上がりになります。

硬いパーツ（ボタンなど）は位置だけを動かし、柔らかい布の部分だけをこのRBFでフィットさせることで、リアリティのある衣装が出来上がります。
